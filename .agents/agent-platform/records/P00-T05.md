## 只读探测契约

公开入口为 **GET `/api/agent-platform/capabilities`**，复用现有API限流、审计等中间件。仅这个方法及精确路径豁免总开关；禁用时返回HTTP200和禁用有效值，HEAD、写方法、子路径及相似路径不获得豁免，业务新准入仍返回503。开启总开关也不会注册未实现的工作区或Run处理器。

成功响应保留 `success/code/message/request_id/data` 五字段，code为 `OK`，响应头为 `Cache-Control: no-store` 和既有 `X-Oneapi-Request-Id`。data为：

```json
{
  "schema_version": 1,
  "enabled": false,
  "worker_enabled": false,
  "mcp_enabled": false,
  "skills_enabled": false,
  "scripts_enabled": false,
  "runtime_ready": false
}
```

五个开关继续使用P00-T04有效依赖。当前运行引擎未实现，即使五项全部开启，`runtime_ready`仍为false。该探测不返回用户、Team/Workspace、资源权限或连接信息，也不从query/header接受作用域；未来工作区级 `W/capabilities` 需要独立资源授权。

`AgentScope`只表示内部归属，不是允许操作的依据；`RequestContext.Scope`须由后续真实身份/资源授权适配器绑定，公开Probe不绑定Scope。Context只传递请求元数据，本批没有实现worker身份、取消协议或租约。共享错误类型保持原503拒绝的空field_errors和retryable=false，未提前实现完整错误目录与内部异常映射。

前端客户端使用统一api、`requireServerSuccess`和Zod检查必需字段及类型，拒绝失败或畸形响应，允许并剥离未知可选字段。网络错误保持原对象，业务错误保留响应来源；没有从旧status缓存、本地存储推断准入，也没有发起后台查询。
