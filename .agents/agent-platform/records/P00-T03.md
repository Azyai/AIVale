表数不包含环境标记表。元数据比较剔除行数估算、索引基数、时间戳和自增游标等运行统计，保留实际类型、默认值、可空性、字符集、索引与约束。这里的重启指关闭数据库连接并重新执行应用数据库启动入口，测试期间没有反复重启 MySQL 服务进程。

数据覆盖 users、tokens、channels、teams、team_members、主库/独立日志库 logs 及 options；比较这些表的所有列和行。断言包含中文用户/渠道/日志内容、个人 Token key 与模型限制、原 Token.TeamId 保持0、auth_version，以及大于 INT32 的用户额度、渠道用量和团队额度。金额仅是固定样例，不调用计费结算。

首次升级还在迁移前冻结主库四张旧表和独立日志表的所有旧投影列及行，迁移后以同一列集对比；因此 email、password、Token用量、渠道key/models等已种入的旧字段也受到保护。新增列不参与这次前后比较，升级摘要明确输出 `legacy_projection_preserved=true`。两次重启再比较当前完整结构及代表性表全部行。

负例是实际数据库写入，被唯一约束拒绝；如果约束消失，测试要求的 MySQL 1062 断言就会失败。统一入口还检查 Go 退出码、SKIP、两个子场景及总测试pass、摘要来自对应子测试、各3次启动、严格布尔/整数类型、实际MySQL版本和升级来源；缺少任一证据不得作为通过。未配置 DSN 时的普通 Go 测试编译与 SKIP 仅作为开发行为检查，没有计入此次真实验收结果。

对统一入口的实际结果判定代码段另做了13例输入重放：真实有效报告接受；非零退出、SKIP、失败事件、缺fresh、缺upgrade、缺总测试pass、缺子测试pass、字符串`"false"`布尔值、字符串启动次数、版本不符、升级标签不符和缺旧投影保留证据等12个异常均拒绝，13/13符合预期。重放使用本次真实报告和脚本中的判定段，不启动第二套模拟数据库；本机明细在该运行目录 `gate-replay.json`。不将该重放描述为13次真实数据库测试。
