## 服务端关闭与排空语义

生产路由总开关按段边界匹配 `/api/agent-platform`、`/v1/agents`、`/v1/agent-runs`，覆盖直接请求和未注册路由。关闭时新入口返回 HTTP503、既有 `AG_RUNTIME_UNAVAILABLE`、现有 request_id、no-store，以及冻结错误契约的 `data.field_errors=[]` 和 `data.retryable=false`；禁用状态等待管理员调整，不引导自动重试。相似前缀及旧模型/Team 路径不受该 gate 影响。子功能有独立 `RequireAgentFeature` 供对应后续路由接入。

GET/HEAD 单 Run、GET/HEAD 单 Run events、POST 单 Run cancel 保留到后续普通认证和处理链，不因关闭新准入而丢失查询或取消路径。此规则只放行功能开关，既不实现处理器也不授予访问权限。

关闭后不撤销已经通过准入的请求上下文；未来 worker 每次新 claim 前读取 `CanClaimNewWork`。本批用受通道控制的已入站 HTTP 回调验证旧请求继续完成、新请求拒绝，未将其称为真实 Agent 队列、租约或 worker 排空。真实队列和受控取消在 P03 接线验收。
