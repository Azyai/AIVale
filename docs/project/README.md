业务范围和任务依赖以现行开发计划为准：本地原件为 `E:/Project/AIVale/docs/AIVale-一体化智能体平台-详细设计与分批开发计划.md`，仓库镜像为 [AI能力调度平台详细设计与分批开发计划](../../.agents/agent-platform/design-and-development-plan.md)。v1.21保留原P00–P11，新增P12–P14与R01–R08；P02-T03至T07提供定义/草稿、发布、生命周期及真实编辑、发布和版本历史页面，P02-T08/T09增加Run主表、受控内部创建、只读预算准备及调用关联，P03-T01增加步骤/事件及事务发件箱恢复基础，正式运行仍关闭；实际验收方式见[测试与验收](07-acceptance.md)。旧验收报告路径只作历史引用，对应报告不再维护或入库。

测试源码和专用夹具只在本地保存、执行。公开 CI 只做构建与静态检查；没有本地用例时不能宣称测试或验收通过。详细报告、日志、截图和结果文件只放入已忽略的本地目录，提交正文或交付说明记录必要的验证摘要。

其他开发约束继续遵循 [仓库约定](../../AGENTS.md)、[前端约定](../../web/AGENTS.md) 及相应领域规则。契约、运行配置、构建元数据和许可证按正常规则维护。

开发先读 01、04 及当前计划任务；运行与外部能力变更加读 02、03；数据与安全变更加读 05、06；交付前核对 07–09。计划定义产品与契约，规范定义工程要求，代码与有效验证决定实际实现边界。发现不一致先核对并同步口径，不能把规划条目当作已上线能力。
