业务范围和任务依赖以已确认的开发计划为准：本地原件为 `E:/Project/AIVale/docs/AIVale-一体化智能体平台-详细设计与分批开发计划.md`，仓库既有镜像为 [详细设计与分批开发计划](../../.agents/agent-platform/design-and-development-plan.md)。本次规范不改写两份计划；其中旧验收报告路径只作历史引用，对应报告不再维护或入库。

测试源码和专用夹具只在本地保存、执行。公开 CI 只做构建与静态检查；没有本地用例时不能宣称测试或验收通过。详细报告、日志、截图和结果文件只放入已忽略的本地目录，提交正文或交付说明记录必要的验证摘要。

其他开发约束继续遵循 [仓库约定](../../AGENTS.md)、[前端约定](../../web/AGENTS.md) 及相应领域规则。契约、运行配置、构建元数据和许可证按正常规则维护。
